# 接口路径差异对照

更新时间：2026-05-24

本文为代码实现（以 `backend/api/main.go` 为准）与 `docs/` 中接口文档差异快速对照，便于联调时统一口径。

1) 开放平台前缀
- 文档中有记载：`/api/v1/open/platform/*`（部分文档、历史说明）
- 实际代码路由：`/api/v1/platform/*`，并在路由组上使用 `OpenAPISignatureMiddleware()`（签名校验）。

建议：以代码为准或统一修改文档至 `/api/v1/platform/*`，并在文档中注明需签名及校验方式。

2) AI / 解析 / 适配路由
- 文档例：AI 引擎内部接口（`/upload`、`/lessons/{id}`、`/chat` 等）存在于 `ai_engine` 服务。
- 后端暴露的 AI 适配路由主要集中在：`/api/v1/ai/*`（例如 `POST /api/v1/ai/coursewares/{courseId}/ask`）和兼容适配的 `/api/v1/lesson/*` `/api/v1/qa/*`（带签名中间件）。

3) SSE 问答流
- 前端文档优先使用 `POST /api/student/qa/stream`（旧版）或 `POST /api/v1/student/qa/stream`（v1）。
- 约定事件类型：`token`、`sentence`、`final`。请前端保持与后端一致的解析逻辑。

4) 公开课件预览
- 文档与代码一致：`GET /api/courseware/{courseId}/page/{pageNum}` 与 `GET /api/v1/courseware/{courseId}/page/{pageNum}` 均可用于图片/302 重定向预览。

5) 已知测试脚本注意项
- `scripts/test-p0ab-api.ps1` 在断言处对 PowerShell 布尔转换存在严格检查（期待布尔值但获得字符串），该错误来自脚本参数/断言使用，不是后端接口本身。建议脚本中使用 `$true/$false` 或将返回值显式转换为布尔再断言。

6) 建议行动项（短期）
- 统一文档口径：将 `docs` 中所有“open/platform”相关条目改为 `/api/v1/platform/*` 并注明签名。或反过来修改代码并添加兼容路由（若需保持文档不变）。
- 在 `docs/当前运行接口清单.md` 顶部增加一行："以代码实现为准（最新路由以 `backend/api/main.go` 为准）"。

结束。
