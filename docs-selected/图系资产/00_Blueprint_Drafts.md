## D01 — 五环业务闭环总览图

**对应PPT：** P02 | **小册子：** M02 | **目标文件：** `01_Business_Loop.mmd`

### L1 — 五环主节点（宏观业务闭环）

```
[教师上传课件] → [AI解析生成智课] → [学生学习+问答] → [断点续学] → [学情回传教师] → (回到起点)
```

### L2 — 每环展开内容

| 环节 | L1节点 | L2展开 |
|------|--------|--------|
| **①可生成** | 课件上传 | 文件（PPT/PDF）→ 三阶段解耦解析 → 结构化节点树 → 逐节点脚本 → 语音合成输出 |

| **③可提问** | 上下文问答 | 学生提问 → 三级级联上下文构建 → 课程知识优先检索 → 苏格拉底式引导回答 → 答案绑定溯源页码 |
| **④可续接** | 断点续学 | 理解程度三态判定（none/partial/full）→ 续讲/补充/重讲选择 → 节点级精确恢复 |

### L3 — 量化数据标注

- 每个环节标注典型耗时指标
- 数据流箭头标注方向（实线=主流程，虚线=数据回传）
- 底部脚注：标注关键算法依据（如理解程度三态判定来自AI引擎模块）

### 连接线规则

```
主环：实线箭头 + 标注"触发条件"
回传：虚线箭头 + 标注"数据类型"
例外：某环节解析失败 → 分支线标注降级路径
```

## D03 — 课件解析管线·三阶段解耦解析图

**对应PPT：** P06,P11,P12 | **小册子：** M04 | **目标文件：** `03_Parse_Pipeline.mmd`

### L1 — 三阶段主管线

```
[原始课件] → Stage1: Markdown理解 → Stage2: 节点树构建 → Stage3: 逐节点脚本生成 → [结构化讲稿]
     ↓                                                        ↓                      ↓
  [降级模板] ← 异常             [降级模板] ← 异常             [降级模板] ← 异常
```

### L2 — 每阶段展开

**Stage1 — Markdown理解**
```
输入：课件原始文本 (max 3500 chars)
处理：大模型解析 → 提取关键知识点 → 规范化文本结构
约束：JSON Schema strict (additionalProperties: false)
输出：{"normalized_markdown": "...", "key_points": ["...", "..."]}
```

**Stage2 — 节点树构建**
```
输入：Stage1输出 (normalized_markdown + key_points)
处理：识别教学单元边界 → 构建层级化节点树 → 计算前置依赖关系
约束：节点node_id必须唯一，prerequisites必须指向已存在节点
输出：{"nodes": [{"node_id": "...", "title": "...", "summary": "...", 
              "source_span": "...", "prerequisites": ["..."]}]}
```

**Stage3 — 逐节点脚本生成**
```
输入：Stage2输出 (节点树)
处理：为每个节点生成讲稿 → 按段类型组织（开场/讲解/互动/过渡）
约束：每个segment必填segment_id/text/node_id/segment_type/estimated_seconds
输出：{"scripts": [{"node_id": "...", "title": "...", "script": "...", 
                   "segments": [...]}]}
```

### L3 — 容错路径

| 故障场景 | 容错行为 |
|---------|---------|
| Stage1 LLM异常 | 回退到预处理模板（_fallback_pipeline） |
| Stage2节点树为空 | 使用fallback节点树 |
| Stage3脚本为空 | 使用fallback脚本 |
| 节点引用无效 | normalize_stage3_scripts自动映射到有效node_id |
| 双向映射不一致 | align_node_segment_mapping修复 |

### 量化标注

| 位置 | 标注 |
|------|------|
| 每个阶段输入 | 数据格式 + 约束条件 |
| 阶段间 | "独立可优化" |
| 降级分支 | "LLM失败→预置模板" |

## D04 — 本页优先RAG+问答流程图

**对应PPT：** P07,P13 | **小册子：** M04 | **目标文件：** `04_RAG_QA_Flow.mmd`

### L1 — 主流程

```
[学生提问] → [上下文构建] → [检索增强] → [苏格拉底式生成] → [流式推送] → [学生看到回答]
                ↑                         ↑                      ↑
           [课程知识库]            [苏格拉底约束提示词]       [SSE三事件]
```

### L2 — 三个级联上下文

| 级联层级 | 触发条件 | 内容范围 | 数据来源 |
|:-------:|---------|---------|---------|
| **L1 节点优先** | node_id有效且匹配 | 目标节点ScriptSegments | TeachingNode.ScriptSegmentsJSON |
| **L2 页面补充** | L1不足以上下问答 | 当前页全部TeachingNode | loadTeachingNodesByPage |
| **L3 全页兜底** | L2仍不足 | CoursePage.SourceText拼接 | CoursePage全页文本 |

### L3 — 问答生成的四个约束

| 约束 | 内容 | 实现方式 |
|------|------|---------|
| 知识约束 | 优先检索课程内容，不允许自由发挥 | 三级级联上下文注入 |
| 苏格拉底约束 | 严禁直接给答案，先确认卡点再引导 | 系统提示词强制指令 |
| 溯源约束 | 回答必须绑定课件页码 | final事件携带source_page |
| 流式约束 | 逐词推送->完整回答->结构化元数据分三段 | SSE token/sentence/final |

### 理解度判定流

```
[学生回答/交互] → LLM综合语义分析 → 判定(understandingLevel)
                                          │
                    ┌──────────────────────┼──────────────────────┐
                    ▼                      ▼                      ▼
             none(未理解)             partial(部分理解)        full(已理解)
                    │                      │                      │
                    ▼                      ▼                      ▼
              执行续讲                 执行补充讲解              跳过
         (ReteachScript)          (ScriptText定位卡点)      (下一节点继续)
```

### 降级路径

```
LLM判定不可用 → 中文教育关键词匹配降级 → RETEACH_KEYWORDS匹配判定
```

## D05 — 多态断点续学状态机图

**对应PPT：** P08,P13 | **小册子：** M04 | **目标文件：** `05_Resume_StateMachine.mmd`

### L1 — 学习状态流转

```
[讲授中] ──学生提问──▶ [问答中] ──回答完成──▶ [判定理解程度] ──▶ [回到讲授]
   ▲                      │                                        │
   │                      │ (打断时保存)                            │
   └──────────────────────┴────────────────────────────────────────┘
                         [打断继续] ──恢复──▶ [续接决策]
                                                  │
                         ┌────────────────────────┼────────────────────────┐
                         ▼                        ▼                        ▼
                    [重讲模式]               [补充模式]               [跳过模式]
                    none→重讲节点            partial→卡点继续          full→下一节点
                    ReteachScript           ScriptText定位             正常推进
```

### L2 — 状态持久化

```
打断时保存的三元组：
  resumePage: int        → 续接页码
  resumeNodeID: string   → 续接节点ID（精确到节点）
  resumeSec: int         → 续接秒数（精确到音频位置）
```

### L3 — 决策依据

| 理解程度 | 判定条件（LLM综合） | 续接模式 | 使用数据 |
|---------|-------------------|---------|---------|
| none | 学生表示完全不懂、答错率>50%、追问同类问题 | 回退重讲 | ReteachScript覆盖讲授 |
| partial | 理解主要概念但细节模糊、部分回答正确 | 补充讲解 | ScriptText定位卡点段落 |
| full | 学生能正确复述/应用、独立完成练习 | 跳过继续 | 下一节点从头开始 |

## D06 — 双引擎降级时序图

**对应PPT：** P05,P10 | **小册子：** M03 | **目标文件：** `06_Fallback_Sequence.mmd`

### 正常时序

```
编排层 ──POST /workflow/parse──▶ Dify主引擎
Dify主引擎 ──HTTP 200 + result──▶ 编排层
编排层 ──result──▶ 前端
```

### 降级时序

```
编排层 ──POST /workflow/parse──▶ Dify主引擎
Dify主引擎 ──HTTP 5xx/timout──▶ 编排层
编排层 ──POST /parse (同请求体)──▶ 本地引擎(127.0.0.1:8000)
本地引擎 ──HTTP 200 + result──▶ 编排层
编排层 ──result──▶ 前端
```

### 双失败时序

```
编排层 → Dify → 失败
编排层 → 本地引擎 → 失败
编排层 → 返回明确降级状态码 → 业务层兜底
```

### 量化标注

| 位置 | 标注 |
|------|------|
| Dify请求 | "主路径" |
| 本地引擎请求 | "降级路径（自动切换，对用户透明）" |
| 双失败 | "返回降级状态码" |
