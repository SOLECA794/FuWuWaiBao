# 图系资产目录（Diagram Assets）

> 统一收口于 `docs-selected/图系资产/`
> 包含图系资产字典、蓝图草案、独立.mmd源文件、量化锚点参考

---

## 目录结构

```
docs-selected/图系资产/
│
├── README.md                            ← 本文件（目录索引）
├── 00_Diagram_Assets_Dictionary.md      ← Phase 1: 10张图资产清单
├── 00_Blueprint_Drafts.md               ← Phase 2: 10张图L1-L3骨架草案
│
├── source/                              ← 独立.mmd源文件（独立可编辑）
│   ├── 02_System_Architecture.mmd       ← 系统架构全景
│   ├── 03_Parse_Pipeline.mmd            ← 三阶段解析管线
│   ├── 04_RAG_QA_Flow.mmd              ← 本页优先RAG+问答流
│   ├── 05_Resume_StateMachine.mmd       ← 多态断点续学状态机
│   └── (补充图中...)
│
└── reference/                           ← 量化锚点数据集（集中管理）
    ├── 01_architecture_anchors.md       ← 架构侧锚点
    └── 02_algorithm_anchors.md          ← 算法侧锚点
```

## 支持微调

每张图独立`.mmd`文件，改一张不影响其他。锚点数据集中记录在`reference/`下，一处修改全局同步。
