# 教师端 × 学生端 联合业务交互流程图

> 核心理念：不分裂，两者综合，互动闭环。教师生产内容 → 学生消费学习 → 学情回传 → 教师优化 → 循环。

## 流程说明

### 三个关键交互点

| 交互点 | 方向 | 含义 |
|--------|------|------|
| 课程发布 `F` | 教师 → 学生 | 教师审阅确认后发布，学生端才可学习 |
| 学情面板 `S` | 学生 → 教师 | 学生的提问、理解程度、卡点数据回传到教师端 |
| 修改重发 `W → F` | 教师 → 学生 | 教师基于学情优化内容后重新发布，闭环完成 |

### 四个决策节点

| 决策点 | 角色 | 分支 |
|--------|------|------|
| 教师审阅 `D` | 教师 | 修改 / 确认发布 |
| 学生遇疑 `I` | 学生 | 继续推进 / 发起提问 |
| 理解程度 `N` | 系统 | full 续讲 / partial 补充 / none 回退 |
| 共性问题 `T → V` | 教师 | 个别追踪 / 共性补讲 / 持续监控 |

### 两条可选路径

| 路径 | 触发条件 | 流向 |
|------|----------|------|
| 错题复盘 `R` | 练习出错 | 错题回链知识节点 → 薄弱点讲解 → 回到学习 |
| 学情回传 `S` | 任何学生学习行为 | 提问/答案/理解度数据 → 教师面板 → 可能触发修改重发 |

### 闭环一句话

> 教师上传 → 解析成节点 → 教师编辑发布 → 学生按节点学习 → 遇疑问答 → 系统判断理解度 → 返回续接位置 → 学情回传 → 教师看到卡点 → 修改讲稿 → 重新发布 → 学生学习更新内容 → 循环
